GitHub リポジトリを Cloudflare で公開する手順（無料枠）

GitHub 上の静的サイト（HTML / CSS / JS）を、Cloudflare Pages や Workers でも無料で公開できます。 以下の手順で登録すると、*.pages.dev や *.workers.dev の URL が発行され、GitHub Pages と並行して配信できます。

1. Cloudflare Pages で静的サイトを公開する

  1. Cloudflare ダッシュボードにログイン → Workers & Pages → Create
  2. Pages を選び、GitHub リポジトリを接続する
  3. 設定例（ビルド不要の静的サイトの場合）：
    • Production branch: main（またはデフォルトブランチ）
    • Build command: 空欄でOK
    • Build output directory: /（リポジトリルート）
  4. Deploy すると https://プロジェクト名.pages.dev のような URL が発行される

これで GitHub Pages と同じ内容が Cloudflare 側でも公開されます。両方が同時に動いても衝突しません。

2. ASCII Counter Worker を公開する

ASCII Counter Worker は、アクセス数を数えるための小さな API です。URL に GET リクエストが届くたびに カウントを1増やし、更新後の数値だけをプレーンテキストで返します。カウントは SQLite ストレージを使う Durable Object に保存されるため、別のリクエストでも引き継がれます。 ただし数えているのは人やユニーク訪問者ではなくリクエストです。ページを再読み込みした場合や、 同じ URL を複数回呼び出した場合も、そのたびに増加します。

デプロイには、Worker の処理を書く src/index.js と、Worker 名や Durable Object のバインディング、SQLite ストレージを設定する wrangler.jsonc の2つのファイルが必要です。どちらか一方だけではデプロイできません。

Node.js と npx を用意し、まず作業用フォルダーを作成します。

mkdir -p ascii-visitor-counter/src
cd ascii-visitor-counter

ファイル1：src/index.js（Worker の処理）

import { DurableObject } from "cloudflare:workers";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, OPTIONS",
  "Cache-Control": "no-store",
};

const textHeaders = {
  ...corsHeaders,
  "Content-Type": "text/plain; charset=utf-8",
};

export default {
  async fetch(request, env) {
    const url = new URL(request.url);

    if (url.pathname !== "/") {
      return new Response("Not found", { status: 404 });
    }

    if (request.method === "OPTIONS") {
      return new Response(null, {
        status: 204,
        headers: corsHeaders,
      });
    }

    if (request.method !== "GET") {
      return new Response("Method not allowed", {
        status: 405,
        headers: { ...corsHeaders, Allow: "GET, OPTIONS" },
      });
    }

    try {
      const id = env.COUNTER.idFromName("global");
      const counter = env.COUNTER.get(id);
      const count = await counter.increment();

      return new Response(String(count), { headers: textHeaders });
    } catch (error) {
      console.error("Counter increment failed:", error);
      return new Response("ERROR!", { headers: textHeaders });
    }
  },
};

export class Counter extends DurableObject {
  async increment() {
    const count = (await this.ctx.storage.get("count")) ?? 0;
    const nextCount = count + 1;
    await this.ctx.storage.put("count", nextCount);
    return nextCount;
  }
}

ファイル2：wrangler.jsonc（作業用フォルダー直下に保存する設定）

{
  "name": "ascii-visitor-counter",
  "main": "src/index.js",
  "compatibility_date": "2026-10-30",
  "durable_objects": {
    "bindings": [
      {
        "name": "COUNTER",
        "class_name": "Counter"
      }
    ]
  },
  "exports": {
    "Counter": {
      "type": "durable-object",
      "storage": "sqlite"
    }
  }
}

2つのファイルを保存したら、作業用フォルダーで初回ログインとデプロイを実行します。

npx wrangler login
npx wrangler deploy

デプロイ後に表示される https://ascii-visitor-counter.<サブドメイン>.workers.dev/ の URL を使います。

補足・注意

  • GitHub Pages と Cloudflare は同じリポジトリをソースにしても独立して動きます。
  • Workers の無料枠には1日あたりのリクエスト上限があります。個人・小規模な用途では通常十分です。
  • Counter Worker はこのページから呼び出せるよう、クロスオリジンの GET リクエストを許可しています。 URL を知っていれば誰でもリクエストでき、そのたびにカウントが増えます。
