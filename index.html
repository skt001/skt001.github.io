GitHub リポジトリを Cloudflare で公開する手順（無料枠）

GitHub 上の静的サイト（HTML / CSS / JS）を、Cloudflare Pages や Workers でも無料で公開できます。 以下の手順で登録すると、*.pages.dev や *.workers.dev の URL が発行され、GitHub Pages と並行して配信できます。

1. Cloudflare Pages で静的サイトを公開する

  1. Cloudflare ダッシュボードにログイン → Workers & Pages → Create
  2. Pages を選び、GitHub リポジトリを接続する
  3. 設定例（ビルド不要の静的サイトの場合）：
    • Production branch: main（またはデフォルトブランチ）
    • Build command: 空欄でOK
    • Build output directory: /（リポジトリルート）
  4. Deploy すると https://プロジェクト名.pages.dev のような URL が発行される

これで GitHub Pages と同じ内容が Cloudflare 側でも公開されます。両方が同時に動いても衝突しません。

2. Cloudflare Workers で簡単な API を公開する

静的ファイルだけでなく、簡単なサーバーレス関数も無料枠で公開できます。

  1. Cloudflare ダッシュボード → Workers & Pages → Create → Worker
  2. 名前を付けて Deploy（例: hello-demo）
  3. 出てきたコードを次のように書き換えて Save and Deploy
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const name = url.searchParams.get("name") || "World";
    const data = {
      message: `こんにちは、${name}さん！`,
      time: new Date().toISOString(),
      worker: "hello-demo"
    };
    return new Response(JSON.stringify(data, null, 2), {
      headers: {
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*"
      }
    });
  }
};

デプロイ後、https://hello-demo.あなたのサブドメイン.workers.dev のような URL が発行されます。

ブラウザや他のページからこの URL を叩くと、JSON が返ってきます。

補足・注意

  • GitHub Pages と Cloudflare は同じリポジトリをソースにしても独立して動きます。
  • Workers の無料枠には1日あたりのリクエスト上限があります。個人・小規模な用途では通常十分です。
  • 上記サンプルでは CORS を通すために Access-Control-Allow-Origin: * を付けています。本番で公開する場合は、許可するオリジンを制限した方が安全です。
