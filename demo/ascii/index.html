8×8 ASCII PNG Generator

PNGを保存

使い方

入力したテキストを 8x8 ピクセルのビットマップフォントで描画し、PNG 画像にします。 Scale は拡大率（整数）で、「PNGを保存」から画像をダウンロードできます。 フォントに含まれない文字は何も描画されません。

ファイル

  • ascii.js — Canvas で PNG の data URL を生成する renderAscii 関数
  • glyphs.js — 1文字 8 バイト（1bit/pixel、最上位ビットが左端）のグリフデータ
  • README.txt — 詳細な説明

自分のページで使う

ascii.js と glyphs.js を同じフォルダーに置き、ES モジュールとして読み込みます。

<img id="out">
<script type="module">
  import { renderAscii } from "./ascii.js";
  document.querySelector("#out").src =
    renderAscii("HELLO", { scale: 4 });
</script>

オプション:

  • scale — 整数の拡大率（既定 1）
  • foreground — 文字色の CSS color（既定 "#fff"。背景は常に黒）
  • spacing — 文字間の追加ピクセル数（既定 0）

モジュールの読み込みには HTTP(S) が必要です。file:// で直接開くと動かないことがあります。
