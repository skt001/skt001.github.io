カウント取得中…

使い方

このページを開くと Cloudflare Worker に GET リクエストを送り、返ってきたカウント数値を 6 桁（0 埋め）で 8x8 ピクセルフォントの画像として表示します。 訪問者数ではなくリクエスト数のカウントで、再読み込みのたびに増えます。 取得に失敗した場合は、画像の位置にエラーメッセージが表示されます。

ファイル

  • ascii.js — 文字列を PNG の data URL に変換する renderAscii 関数
  • glyphs.js — 8x8 ピクセルのグリフデータ
  • worker/src/index.js — カウントを増やして数値を返す Worker
  • worker/wrangler.jsonc — Worker と Durable Object の設定
  • worker/README.md — Worker のデプロイ・動作確認手順

自分のページで使う

Worker をデプロイしたあと、その URL に置き換えて、ascii.js と glyphs.js を同じフォルダーに置いたページから次のように呼び出します。 

<img id="counter">
<script type="module">
  import { renderAscii } from "./ascii.js";
  const res = await fetch("https://ascii-visitor-counter.<サブドメイン>.workers.dev/");
  const count = await res.text();
  document.querySelector("#counter").src =
    renderAscii(count.padStart(6, "0"), { scale: 4 });
</script>

Worker のデプロイ方法はトップページの手順を参照してください。
